# A Chama do Pampa

Um livro-jogo da Maroca pelos pampas do Rio Grande: uma aventura em que os dados decidem o caminho.

**Jogue agora:** https://cabral.github.io/chama_do_pampa/

## Conteúdo

| Caminho | O que é |
|---|---|
| `index.html`, `style.css`, `game.js`, `data.js`, `assets/` | O jogo web (publicado via GitHub Pages) |
| `downloads/A-Chama-do-Pampa-Jogo-offline.html` | Versão em um único arquivo HTML, funciona offline |
| `downloads/A-Chama-do-Pampa.pdf` | O livro em PDF |
| `downloads/Mapa-e-peao-para-imprimir.pdf` | Mapa e peão para imprimir |
| `downloads/Capa-do-jogo.jpg`, `downloads/Previa-O-campo-do-Boitata.jpg` | Capa e prévia |

## Rodar localmente

Não há dependências nem etapa de build. Abra `index.html` no navegador, ou sirva a pasta:

```sh
python3 -m http.server 8000
```
